# متجر التوفيق – AL TAOUFIK

نسخة تأسيسية لمتجر إلكتروني عربي متجاوب بهوية بصرية راقية بالخمري والفحمي، مع لوحة إدارة منفصلة وحساب مدير واحد.

تم اعتماد أيقونات SVG خطية موحدة بدلاً من الرموز التعبيرية لضمان مظهر احترافي ومتناسق على الهاتف والحاسوب.

## محتويات النسخة
- واجهة متجر عربية RTL مناسبة للهاتف والحاسوب.
- صورة الوجه الإعلامي في `assets/images/owner.jpg`.
- تصنيفات وبحث وعربة تسوق محلية.
- نموذج تسجيل طلبات للزوار.
- لوحة إدارة محمية بتسجيل دخول Supabase.
- إضافة/تعديل/حذف المنتجات ونشرها وإخفاؤها.
- متابعة الطلبات وتحديث حالتها.
- صفحة ماسح باركود بالكاميرا (تتطلب HTTPS).
- ملف SQL لإنشاء الجداول وسياسات RLS.

## خطوات التشغيل

### 1) إنشاء مشروع Supabase
1. افتح https://supabase.com وأنشئ مشروعاً جديداً باسم `al-taoufik`.
2. احتفظ بعنوان المشروع ومفتاح `anon` أو `publishable` فقط للاستخدام في الواجهة.
3. من SQL Editor افتح `database/schema.sql` والصق محتواه ثم اضغط Run.

### 2) إنشاء حساب المدير الوحيد
1. من Supabase افتح Authentication ثم Users.
2. أضف مستخدماً جديداً ببريد المدير وكلمة مرور قوية.
3. انسخ البريد نفسه، ثم في SQL Editor نفّذ الأمر الموجود آخر `schema.sql` بعد استبدال `YOUR-ADMIN-EMAIL` بالبريد الفعلي.
4. لا تنشئ رابط تسجيل عام للمدير. إنشاء الحساب يتم من لوحة Supabase فقط.
5. صفحة دخول المدير هي `admin/login.html`.

### 3) ربط الواجهة بقاعدة البيانات
افتح `js/config.js` وضع:
- `SUPABASE_URL`: عنوان مشروعك.
- `SUPABASE_ANON_KEY`: مفتاح anon/publishable.

لا تضع `service_role` أو أي مفتاح سري في ملفات المتصفح أو GitHub.

### 4) النشر
يمكن رفع مجلد المشروع إلى GitHub ثم ربط المستودع بـ Vercel أو Netlify. أضف نطاق الموقع إلى Supabase Authentication > URL Configuration عند الحاجة. يجب أن يعمل الموقع عبر HTTPS حتى تعمل الكاميرا.

## ملاحظات مهمة قبل البيع الفعلي
- لا تعتبر هذا الإصدار جاهزاً لقبول مدفوعات إلكترونية؛ الدفع الإلكتروني يحتاج بوابة متوافقة مع موريتانيا وتكامل خادمي موثوق.
- نموذج الطلب الحالي يسجل بيانات العميل والطلب، ولا يحجز المخزون أو يخصم الكمية تلقائياً.
- في النسخة الحالية يحسب المتصفح الإجمالي المعروض؛ قبل الإطلاق التجاري ينبغي نقل حساب الأسعار والتحقق من المخزون إلى دالة خادمية/قاعدة بيانات، مع تحديد قواعد التوصيل والإلغاء.
- صفحة إدارة واجهة المتجر حالياً تعرض تعليمات تغيير صورة الوجه الإعلامي؛ محرر الحملات الإعلانية الديناميكي مرحلة تطوير لاحقة.
- أضف المنتجات والصور الحقيقية والأسعار وسياسة الخصوصية والاسترجاع والتوصيل قبل فتح المتجر للجمهور.

## بيانات المدير
هذا المشروع لا يحتوي كلمة مرور افتراضية. أنشئ حساباً واحداً بنفسك في Supabase، ثم امنحه دور admin عبر SQL أعلاه.
